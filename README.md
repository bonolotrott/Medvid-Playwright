\# 🏥 MedVid - Smart Healthcare System



A full-stack healthcare application that solves real-world hospital problems:

\- Lost patient files

\- Crowded waiting rooms

\- Confusing diagnoses

\- No record of consultations



\## ✨ Features



\- 📝 \*\*Patient Registration\*\* - Create digital medical file (never lost)

\- 🎙️ \*\*Voice Notes\*\* - Doctor and patient voice recordings

\- 📹 \*\*Video Consultations\*\* - Doctor records video explanation

\- 📤 \*\*Patient Video Upload\*\* - Upload symptom videos for better diagnosis

\- 📋 \*\*Consultation History\*\* - Complete medical history with all media

\- 🔒 \*\*Secure Records\*\* - JWT authentication and encrypted data
